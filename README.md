## 简体中文

### 项目简介

GasNow Web App 是一个全面的 Web 应用，用于实时追踪以太坊及多条 Layer 2 网络的 Gas 费用（Arbitrum、Optimism、Base、Linea、zkSync）。后端由 [GasNow](https://github.com/foreverdesmond/GasNow) 提供数据。

### 功能特性

- **实时 Gas 追踪**：监控 6 条主要网络的 Gas 费用
- **多网络支持**：ETH、Arbitrum、Optimism、Base、Linea、zkSync
- **响应式设计**：适配所有设备
- **博客系统**：关于 Gas 费用与 Layer 2 的科普内容
- **SEO 优化**：针对搜索引擎优化

### 支持的网络

- **Ethereum (ETH)**：主网 Gas 费用追踪
- **Arbitrum One**：Layer 2 扩容方案
- **Optimism**：社区聚焦的 rollup
- **Base**：Coinbase 的机构级方案
- **Linea**：ConsenSys 的 zkEVM 方案
- **zkSync Era**：零知识创新

### 技术栈

- **前端**：React 18、Ant Design
- **路由**：React Router DOM
- **样式**：Ant Design 主题系统
- **构建工具**：Create React App
- **部署**：静态托管就绪

### 快速开始

**环境要求**：Node.js 18+、npm 或 yarn

```bash
# 安装依赖
npm install

# 启动开发服务器
npm start

# 构建生产版本
npm run build
```

## English

### Project Overview

GasNow Web App is a comprehensive web application for tracking real-time gas fees across multiple Ethereum Layer 2 networks including Arbitrum, Optimism, Base, Linea, and zkSync. Backend data is provided by [GasNow](https://github.com/foreverdesmond/GasNow).

### Features

- **Real-time Gas Tracking**: Monitor gas fees across 6 major networks
- **Multi-Network Support**: ETH, Arbitrum, Optimism, Base, Linea, zkSync
- **Responsive Design**: Optimized for all devices
- **Blog System**: Educational content about gas fees and Layer 2 solutions
- **SEO Optimized**: Built with search engine optimization in mind

### Supported Networks

- **Ethereum (ETH)**: Mainnet gas fee tracking
- **Arbitrum One**: Layer 2 scaling solution
- **Optimism**: Community-focused rollup
- **Base**: Coinbase's institutional-grade solution
- **Linea**: ConsenSys's zkEVM solution
- **zkSync Era**: Zero-knowledge innovation

### Tech Stack

- **Frontend**: React 18, Ant Design
- **Routing**: React Router DOM
- **Styling**: Ant Design Theme System
- **Build Tool**: Create React App
- **Deployment**: Static hosting ready

### Quick Start

**Prerequisites**: Node.js 18+, npm or yarn

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```
